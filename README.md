# NoiseRoute

Приложение на базе .NET WPF для визуализации маршрутов летательных аппаратов с интеллектуальным обходом жилых зон в целях минимизации авиационного шума.

## Описание

NoiseRoute - это проект выпускной квалификационной работы (ВКРБ), который предоставляет функции визуализации и оптимизации маршрутов полёта летательных аппаратов. Система автоматически рассчитывает оптимальные траектории, обходя населённые жилые районы при сохранении безопасности и эффективности полёта.

## Возможности

- Визуализация маршрутов полёта на интерактивной карте
- Планирование навигации летательного аппарата
- Автоматическое определение маршрута с обходом жилых зон
- Валидация входных данных и параметров
- Интерфейс на базе Windows Presentation Foundation (WPF)

## Технологический стек

- Фреймворк: .NET 10.0 (Windows)
- UI фреймворк: Windows Presentation Foundation (WPF)
- Визуализация: OxyPlot 2.2.0
- IDE: Visual Studio Community 2026
